How to use the MasterVolumePatcher:
===================================

MasterVolumePatcher requires these Python packages:
- lz4
- capstone
- keystone-engine

You can install the packages with:
py -3 -m pip install lz4 capstone keystone-engine

With that installed, you should be able to run 
"make all" and "make patch" without any issues.
